# 完整客户端范围与验收清单

本文件把当前授权目标拆成可验收功能。上游 `MicYou-iOS/` 仅用于确认功能意图；本项目必须使用独立 Swift 实现，并以真实桌面端协议 `PROTOCOL.md` 为准。用户可见功能参考自上游 `v2`（本地参考 commit `9ee4ea1`），不代表其旧网络协议兼容真实服务端。

## 协议与连接

- [ ] 手动输入主机 / 端口、校验并记住最近连接
- [ ] `_micyou._tcp` mDNS 发现、解析、刷新与失效处理
- [ ] TCP `MicYouCheck1/2` 握手、Connect、8 字节帧、Protobuf 编解码
- [ ] 服务端 Ping / 客户端 Pong、断线识别、可控重连与错误呈现
- [ ] TCP 音频与桌面端 Mute 控制
- [ ] UDP 音频通道（端口 +1）、报文大小限制；需要时再实现 FEC
- [ ] PCM 与 Opus 编解码路径（Opus 必须有可复现的 iOS 构建和许可记录）
- [ ] PluginMessage 收发基础能力（不引入上游插件代码）

## 音频与主界面

- [ ] 麦克风权限与 `AVAudioEngine` 采集；采样率 / 声道设置和协议元数据一致
- [ ] 音频会话与路由（扬声器、耳机、蓝牙）、后台持续采集与中断恢复
- [ ] 系统 Voice Processing / 回声抑制能力；可选 RNNoise 降噪及强度（依赖必须本地化、可构建）
- [ ] 音量可视化、静音、连接状态、无障碍与错误反馈
- [ ] 六种可视化样式：音量环、涟漪、条形、波形、发光、粒子

## 设置、系统集成与发行

- [ ] 深浅色 / OLED 黑、主题色、背景图片管理、外观风格
- [ ] 简体中文、繁体中文、英语；跟随系统
- [ ] 保持屏幕常亮、串流通知、启动时更新检查
- [ ] 本地日志与分享导出、版本与开源许可信息
- [ ] Live Activity 锁屏状态、Dynamic Island 紧凑/展开态、前后台状态同步
- [ ] 开源许可清单、隐私说明、图标、签名 / App Store 配置与 IAP 打赏准备

## 验收层级

1. 协议核心：无外部依赖的单元测试覆盖字节序、Protobuf、流式分帧、畸形输入与大小上限。
2. 工程：可在本地 Xcode / iOS Simulator 编译；资源、扩展、隐私声明均进入构建。
3. 端到端：连接真实 MicYou 桌面端，验证发现、握手、音频、心跳、静音、断线恢复；需实机验证麦克风、后台和 Live Activity。
4. 发行：配置真实 bundle ID、图标、App Store Connect 元数据与打赏商品后，才可称为可发布产品。

## 当前进度

所有条目初始未验收。仅有代码或模拟器成功不能替代真实桌面端与实机验收；遇到缺少设备、签名或桌面端环境时应明确标为阻塞。
